# PID 调参模式使用说明

本模式用于重复比较不同 PID 参数的阶跃响应。它只在收到 `Tune` 命令后启用，不改变普通 `Run` 速度模式和循迹模式的控制流程。

## 1. 安全要求

1. 第一次调试必须架空车轮，确认电机不会带动车体冲出桌面。
2. 建议先使用较小目标，例如 `Tune=80`，确认电机方向和编码器方向正确后再提高。
3. 单次测试包含 500 ms 静止等待和 3000 ms 阶跃运行，结束后自动停车。
4. 被测电机触发过流保护时立即结束调参并全部停车。
5. 测试期间可随时发送 `TuneStop`、`Stop`、`StopAll` 或 `Abort` 停车。

## 2. 最简单的使用方法

以 0 号电机、目标 200 RPM 为例，在 UART0 控制台逐行发送：

```text
Motor=0
Ki=0
Kd=0
Kp=2
Tune=200
```

等待本轮自动结束后，再发送：

```text
Kp=20
Tune=200
```

也可以在 `Tune` 命令中直接指定电机：

```text
Tune=0,200
```

查询或中止：

```text
Tune?
TuneStop
```

## 3. 调参模式做了什么

每次收到合法的 `Tune` 命令后，控制任务按固定顺序执行：

1. 退出循迹、模型辨识、位置控制和角度控制。
2. 停止所有电机，并保存被测电机原来的前馈开关。
3. 关闭被测电机前馈，清空 PID 历史状态。
4. 静止等待 500 ms。
5. 对指定电机直接施加 RPM 阶跃目标，持续 3000 ms。
6. 自动停止所有电机，并恢复原来的前馈开关。

调参期间会绕过目标规划、目标斜坡、输出斜坡、IMU 直行修正和前馈，因此不同 Kp 的瞬态差异不会再被这些整形环节掩盖。PID 内部限幅、电机命令硬限幅、方向保护、编码器滤波和 ADC 过流保护仍然有效。

## 4. 14 通道遥测定义

`Tune` 启动成功后，UART0 每 20 ms 输出一行 14 通道 CSV：

| 通道 | 字段 | 说明 |
|---|---|---|
| CH0 | `t_ms` | 从本轮调参开始计算的时间，单位 ms |
| CH1 | `phase` | 0=空闲，1=静止等待，2=阶跃运行，3=已完成 |
| CH2 | `requested` | 用户请求的阶跃目标 RPM |
| CH3 | `applied` | 本周期实际送入 PID 的目标 RPM |
| CH4 | `rpm` | 编码器测得的实际 RPM |
| CH5 | `error` | PID 本周期误差，等于 `applied-rpm` |
| CH6 | `raw` | PID 内部限幅前计算输出 |
| CH7 | `command` | 方向保护和电机命令硬限幅后的最终命令 |
| CH8 | `p` | 本周期 P 诊断项 |
| CH9 | `i` | 本周期 I 诊断项 |
| CH10 | `d` | 本周期 D 诊断项 |
| CH11 | `kp` | 当前 Kp |
| CH12 | `ki` | 当前 Ki |
| CH13 | `kd` | 当前 Kd |

位置式 PID 的 `p/i/d` 是绝对分量；增量式 PID 的 `p/i/d` 是本周期输出增量。

本工程增量式 PID 统一采用：

```text
Δu = Kp × (e-e1) + Ki × e + Kd × (e-2e1+e2)
u  = u_last + Δu
```

`Ki`、`Kd` 都按每个控制周期定义，不乘除 `dt`；改变控制周期后必须重新调参。`raw` 与 `command` 不相等时，说明输出受到了 PID 内部限幅、方向保护或电机命令硬限幅。

原有普通 `Run` 模式的 11 通道 VOFA 数据格式保持不变。

## 5. Kp 对比验收

比较 `Kp=2` 和 `Kp=20` 时，重点观察阶跃刚开始后的前几个采样点：

1. `phase` 从 1 变为 2 时，`applied` 应直接从 0 跳到设定目标，不应缓慢爬升。
2. `Kp=20` 的首周期 `p` 和 `raw` 应明显大于 `Kp=2`。
3. 如果两者 `command` 都达到同一个限幅值，说明执行器已经饱和；此时不能只看转速曲线判断 Kp 是否生效，应同时查看 `raw`。
4. 测试过程必须始终使用相同电机、目标、供电电压、负载和车轮状态，否则两轮数据不可直接比较。
5. 每次修改 Kp 后重新发送 `Tune`，控制器状态会被重新清空，保证起始条件一致。

## 6. 相关配置

调参参数统一位于 `Config/project_config.h`：

```c
#define PRJ_PID_TUNE_SETTLE_MS            (500U)
#define PRJ_PID_TUNE_STEP_MS              (3000U)
#define PRJ_PID_TUNE_TARGET_RPM_MAX       (300.0f)
#define PRJ_PID_TUNE_TELEMETRY_PERIOD_MS  (20U)
```

通常只需修改以上四个宏，不要在控制任务中散落新的调参常量。
