# 四/五路红外循迹使用说明

## 1. 设备切换

当前工程默认使用五路红外：

```c
/* BSP/Peripherals/bsp_ir.h */
#define BSP_IR_CHANNEL_COUNT    (5U)
```

只需要把这个宏改成 `4U`，即可切换到四路算法。四路模式不使用 `IR_CH5_*`，五路模式要求 `Config/ti_msp_dl_config.h` 中存在 `IR_CH5_PORT`、`IR_CH5_PIN` 和 `IR_CH5_IOMUX`。

如果通过 Keil 预处理选项传入 `BSP_IR_CHANNEL_COUNT=4`，则不需要修改源文件；源文件中的默认值只在没有外部定义时生效。

## 2. 五路传感器物理位置

约定 `CH1 -> CH5` 从车体左侧到右侧：

| 通道 | 相对车体中心的位置 |
|---|---:|
| CH1 | +48.25 mm |
| CH2 | +24.45 mm |
| CH3 | 0 mm |
| CH4 | -24.45 mm |
| CH5 | -48.25 mm |

依据：中间三路外侧跨度为 `48.9 mm`，五路总宽为 `96.5 mm`。算法使用归一化权重：

```text
CH1  +1.9734
CH2  +1.0000
CH3   0.0000
CH4  -1.0000
CH5  -1.9734
```

如果传感器重新安装，只修改 `app_line_track.h` 中的：

```c
#define LINE_TRACK_5CH_MIDDLE_SPAN_MM  (48.9f)
#define LINE_TRACK_5CH_TOTAL_WIDTH_MM  (96.5f)
```

不要在循迹任务中重新写一套权重。

## 3. 红外状态和掩码

BSP 对外统一为 `1=黑线，0=白色`。算法内部的 `black_mask` 使用以下位定义：

```text
bit4 = CH1，最左
bit3 = CH2
bit2 = CH3，中间
bit1 = CH4
bit0 = CH5，最右
```

常见状态：

| `black_mask` | 含义 | 误差约值 |
|---:|---|---:|
| `0x04` | 仅中间路压线 | 0 |
| `0x0C` | CH2、CH3 黑 | +0.50 |
| `0x06` | CH3、CH4 黑 | -0.50 |
| `0x08` | 仅 CH2 黑 | +1.00 |
| `0x02` | 仅 CH4 黑 | -1.00 |
| `0x10` | 仅 CH1 黑 | +1.97 |
| `0x01` | 仅 CH5 黑 | -1.97 |
| `0x0E` | CH2、CH3、CH4 黑，默认横线 | 0 |
| `0x00` | 全白，丢线 | 使用上一次有效方向搜索 |

`line_error > 0` 表示黑线在车体左侧，车辆需要向左修正；`line_error < 0` 表示黑线在车体右侧，车辆需要向右修正。

## 4. 循迹控制逻辑

`app_line_track_step()` 每 5 ms 执行一次以下流程：

1. 读取四路或五路红外；
2. 使用三次逐位多数表决抑制单次毛刺；
3. 按传感器物理位置计算加权偏差；
4. 根据偏差生成连续转向量，并限制相邻周期的突变；
5. 根据转向量降低弯道速度，但不在圆弧中反复急停；
6. 丢线时保存上一次有效偏差，沿上一次方向搜索；
7. 直行且左右轮反馈有效时，使用很小的P修正补偿左右轮速度差；
8. 通过现有 `bsp_motor_set_speed()` 输出左右轮命令。

赛题为连续椭圆/圆弧赛道，默认：

```c
#define LINE_TRACK_RIGHT_ANGLE_ENABLE   (0U)
```

不要在圆弧赛道上打开直角弯保持逻辑。

## 5. 起点/终点横线

五路默认使用 `0x0E` 作为横线掩码，即中间三路同时检测到黑线。该判断是包含判断，因此 `0x0F`、`0x1E`、`0x1F` 也会被当作横线，适应车体轻微偏置和较宽横线。

如果赛道标线实际宽度不同，只覆盖：

```c
#define LINE_TRACK_CROSS_BLACK_MASK   (0x0EU)
```

不需要修改状态机代码。

## 6. 上车前最小验证

1. 临时关闭电机输出，只打印 `ir_raw`、`black_mask`、`line_error`；逐路压黑线，确认 CH1 到 CH5 顺序没有左右反转。
2. 确认中间路黑线时 `black_mask=0x04`、`line_error` 接近 0。
3. 确认最左路黑线时 `line_error` 为正，最右路黑线时为负。
4. 将三路中间传感器同时压在横线上，确认 `black_mask & 0x0E == 0x0E`。
5. 直线低速启动，先观察左右轮同步修正，再逐步提高 `LINE_TRACK_BASE_SPEED`。
6. 车辆丢线时确认会向最后一次有效方向搜索；若搜索过猛，优先降低 `LINE_TRACK_TURN_MAX_ANGLE` 或提高 `LINE_TRACK_LOST_SEARCH_RAMP_MS`。

调试红外瞬时状态时可以暂时设置：

```c
#define LINE_TRACK_FILTER_ENABLE   (0U)
```

实车正常运行建议保持 `1U`，以免单次毛刺触发转向或横线判断。

## 7. 主要可调参数

| 参数 | 作用 | 首选调整方向 |
|---|---|---|
| `LINE_TRACK_BASE_SPEED` | 基础速度 | 先低速，确认不丢线后逐步增加 |
| `LINE_TRACK_TURN_MIN_ANGLE` | 小偏差修正 | 直线左右摆动时降低 |
| `LINE_TRACK_TURN_MAX_ANGLE` | 大偏差修正 | 大弯跟不上时增加，抖动时降低 |
| `LINE_TRACK_TURN_SLEW_STEP` | 转向变化速度 | 左右摆动时降低，响应太慢时增加 |
| `LINE_TRACK_CURVE_MIN_SPEED_RATIO` | 弯道最低速度比例 | 弯道冲出时降低，弯中停顿时增加 |
| `LINE_TRACK_LOST_SEARCH_RAMP_MS` | 丢线后转向渐增时间 | 搜索过猛时增加 |
| `LINE_TRACK_STRAIGHT_SYNC_KP` | 直行两轮同步P系数 | 直行跑偏时小幅增加，低速抖动时降低 |

本模块不新增看门狗、任务或动态内存；业务任务仍只需调用已有的 `app_line_track_init()`、`app_line_track_start()`、`app_line_track_step()` 和 `app_line_track_stop()`。
